# FuelTrack AI - Akıllı Yakıt & Seyahat Analizi

FuelTrack AI, araç sahiplerinin seyahatlerini, yakıt tüketimlerini ve seyahat maliyetlerini kolayca takip etmelerini ve analiz etmelerini sağlayan modern bir web uygulamasıdır. Veriler tarayıcınızda LocalStorage kullanılarak güvenle saklanır.

## Özellikler
* **Seyahat Ekleme:** Rota, katedilen mesafe, alınan yakıt ve litre birim fiyatı ile seyahat kaydı oluşturma.
* **Akıllı Özet Kartları:** Toplam mesafe, toplam yakıt, toplam harcama ve ortalama yakıt tüketimi (L/100km) metriklerinin otomatik hesaplanması ve gösterilmesi.
* **Geçmiş Takibi:** Kaydedilen tüm seyahatlerin listelenmesi ve yönetilmesi.
* **Modern Arayüz:** Tailwind CSS ile tasarlanmış şık ve tamamen duyarlı (responsive) kullanıcı deneyimi.

## Kullanılan Teknolojiler
* **Frontend:** React (Vite ile)
* **Stil & Tasarım:** Tailwind CSS
* **Veri Depolama:** Browser LocalStorage
* **Dağıtım (Deployment):** Netlify
* **Versiyon Kontrolü:** Git & GitHub

## Geliştirme Sürecinde Yapay Zekanın Rolü
Bu projenin geliştirme ve yayınlama sürecinde Gemini yapay zeka asistanından şu aşamalarda aktif olarak destek alınmıştır:
1. **Planlama & Mimari:** Uygulamanın ekran tasarımlarının, bileşen yapısının ve LocalStorage veri modelinin kurgulanması.
2. **Kod Üretimi & Entegrasyon:** React bileşenlerinin yazılması ve Tailwind CSS sınıflarının entegre edilmesi.
3. **Hata Ayıklama (Debugging):** TypeScript'ten JavaScript'e (.jsx) geçiş sürecindeki derleme hatalarının çözülmesi ve Netlify dağıtım optimizasyonlarının yapılması.
